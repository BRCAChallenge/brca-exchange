# SpliceAI gene annotations

## brca_mane_grch38.txt

The `-A` table SpliceAI is run with. Generated by `../make_spliceai_annotation.py`:

```
python insilico/make_spliceai_annotation.py \
    -g MANE.GRCh38.v1.3.ensembl_genomic.gtf.gz \
    -o insilico/spliceai_annotations/brca_mane_grch38.txt
```

Source: MANE v1.3, `MANE.GRCh38.v1.3.ensembl_genomic.gtf.gz`, transcripts
tagged `MANE_Select`. Regenerate from a newer MANE release rather than editing
by hand. SpliceAI parses this file with a bare `pandas.read_csv` and has no
notion of comment lines, which is why this provenance lives here and not in
the table itself.

### Why not `-A grch38`

SpliceAI's packaged table is GENCODE V24 canonical, and its BRCA1 record spans
43,045,629-43,125,483 — 1,334 bases short of NM_007294.4 at the 3' end.
`spliceai.utils.get_delta_scores` overwrites every base of the input window
outside the annotated transcript with N, and the model's receptive field is
5,000 bases either side of each scored position, so that shortfall changes the
score of any variant within ~5 kb of the boundary and drops variants outside
the span entirely. On the BRCA Exchange variant set the packaged table left
1,326 BRCA1 and 53 BRCA2 variants with no SpliceAI score at all.

`BRCA1 c.5467+878_5467+885dup` is the worked example: `DS_AG` 0.00 with the
packaged table, 0.017 with this one, matching the ARIANE service and the Broad
SpliceAI lookup at the same `-D 4999 -M 0`.
